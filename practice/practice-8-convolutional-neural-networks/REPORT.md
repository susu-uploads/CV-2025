## Реализация

Практическая работа разделена на два notebook:

1. `СП-М-О-КЗ-2025-Практика-8-1-БабушкинМВ.ipynb` — загрузка и подготовка датасета.
2. `СП-М-О-КЗ-2025-Практика-8-2-БабушкинМВ.ipynb` — обучение сверточной нейронной сети в PyTorch.

Такое разделение позволяет один раз подготовить набор данных и затем повторять эксперименты по обучению без повторной перепаковки исходных изображений.

## Используемый датасет

В работе используется датасет `Donkeys, Horses & Zebra Images Dataset` с Kaggle:

- [https://www.kaggle.com/datasets/ifeanyinneji/donkeys-horses-zebra-images-dataset](https://www.kaggle.com/datasets/ifeanyinneji/donkeys-horses-zebra-images-dataset)

Исходный набор содержит три класса:

- `donkey`
- `horse`
- `zebra`

Для выполнения задания был сформирован бинарный поднабор из двух классов:

- `horse`
- `zebra`

Это изменение было сделано осознанно, так как пара `horse / zebra` различается лучше, чем `donkey / horse`, и позволяет устойчивее обучить простую CNN из методички.

## Notebook 8.1

В notebook `8.1` выполняются:

- загрузка датасета через `kagglehub`;
- просмотр исходного разбиения `train / test`;
- выбор только двух классов `horse` и `zebra`;
- выделение `val` из исходного `train`;
- перепаковка данных в локальный prepared-набор.

Исходный `test` сохраняется без изменений и используется только для финальной оценки модели.  
Валидационная выборка формируется из исходного `train` с долей `20%`.

После подготовки формируется локальный набор:

- `.data/donkeys-horses-zebra-prepared`

Фактическое разбиение:

- `train`: `500`
- `val`: `124`
- `test`: `156`

Распределение по классам:

### Train

- `zebra`: `192`

### Val

### Test

Во втором notebook используется prepared-датасет из `8.1`.

## Преобразования данных

Для обучающей выборки используются:

- `Resize((224, 224))`
- `RandomHorizontalFlip()`
- `RandomRotation(15)`
- `ToTensor()`
- `Normalize((0.5, 0.5, 0.5), (0.5, 0.5, 0.5))`

Для `val` и `test` используются:

- `Resize((224, 224))`
- `ToTensor()`
- `Normalize((0.5, 0.5, 0.5), (0.5, 0.5, 0.5))`

Таким образом, аугментация используется только на обучении.

## Архитектура модели

Используется простая сверточная сеть:

- `Conv2d(3 -> 16, kernel_size=5x5, stride=2, padding=1)`
- `Conv2d(16 -> 32, kernel_size=5x5, stride=2, padding=1)`
- `Conv2d(32 -> 64, kernel_size=3x3, padding=1)`
- `Linear(64 * 6 * 6 -> 500)`
- `Linear(500 -> 50)`
- `Linear(50 -> 2)`

После каждого сверточного слоя применяется:

- `ReLU`
- `MaxPool2d(2)`

Так как задача бинарная, выходной слой содержит `2` нейрона.

## Параметры обучения

В notebook используются:

- функция потерь: `CrossEntropyLoss`
- оптимизатор: `Adam`
- скорость обучения: `0.001`
- размер батча: `16`
- количество эпох: `10`
- устройство: `MPS`, если доступно
