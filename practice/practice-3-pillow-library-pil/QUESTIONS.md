# Вопросы и ответы для защиты

- **Что такое Pillow (PIL) и зачем она использовалась в работе?**
  Pillow — это библиотека Python для загрузки, сохранения и базовой обработки изображений. В работе она применялась для открытия изображения, преобразований в оттенки серого, квантования и анализа цветовых каналов.

- **Как загружается изображение в Pillow?**
  Для загрузки используется `Image.open(path)`. Эта функция открывает файл изображения и возвращает объект `PIL.Image`.

- **Чем объект `PIL.Image` отличается от массива NumPy?**
  `PIL.Image` — это объект библиотеки Pillow для работы с изображением, а массив NumPy — численное представление пикселей, удобное для индексирования и математических операций.

- **Зачем в работе определялся путь к изображению через `os.getcwd()` и `os.path.join()`?**
  Это позволяет явно понять, из какой директории читается файл, и корректно собрать путь к изображению без ручного ввода полного адреса.

- **Что означает режим изображения в Pillow?**
  Режим задаёт структуру пикселей, например `RGB` для цветного изображения или `L` для изображения в градациях серого.

- **Как в Pillow получить изображение в оттенках серого?**
  Обычно для этого используется преобразование изображения к режиму `L`, где каждый пиксель задаётся одной яркостью.

- **Что такое квантование изображения?**
  Квантование уменьшает количество возможных уровней цвета или яркости. Это упрощает представление изображения и может уменьшать размер или выделять крупные визуальные структуры.

- **Зачем изучать цветовые каналы отдельно?**
  Каждый канал содержит информацию о вкладе соответствующего цвета. Разделение каналов помогает понять структуру изображения и то, как формируется итоговый цвет.

- **Как разделяются цветовые каналы в Pillow?**
  Для этого используется метод `split()`, который возвращает отдельные изображения для каждого канала, например `R`, `G` и `B`.

- **Почему после разделения каналов изображение может выглядеть как чёрно-белое?**
  Потому что каждый отдельный канал хранит только интенсивность одной цветовой компоненты, а не итоговый полный цвет.

- **Зачем переводить изображение из Pillow в массив NumPy?**
  Это нужно для прямого доступа к пикселям по индексам, анализа структуры массива и ручного изменения отдельных каналов или областей изображения.

- **В чём разница между `np.asarray(image)` и `np.array(image)`?**
  Обе функции создают представление изображения как массива, но `np.array` чаще создаёт новый независимый массив, что удобнее для безопасного изменения данных.

- **Что такое индексирование изображения в NumPy?**
  Это обращение к отдельным пикселям, строкам, столбцам, каналам или фрагментам изображения через индексы массива.

- **Как можно вручную убрать один или несколько каналов цвета?**
  После перевода в массив NumPy можно обнулить нужные срезы, например установить значения одного или двух каналов в 0.

- **Почему Pillow часто используют вместе с NumPy и Matplotlib?**
  Pillow удобно открывает изображения, NumPy позволяет работать с ними как с массивами, а Matplotlib нужен для наглядного отображения результатов в ноутбуке.
